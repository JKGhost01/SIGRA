# SIGRA 1.4.1.0 · Sincronización autónoma y privacidad

El catálogo que consume Android puede actualizarse sin visitas al mapa mediante
una tarea del servidor. Incluye instalador de cron por usuario, ejecución cada
minuto con caché y pausas compartidas, logs diarios UTC y códigos de salida de error.

Integra documentos de privacidad, tratamiento, cookies y términos ES/EN,
autorización explícita de reportes y persistencia de versión/fecha. Corrige el
formulario, elimina la ubicación por IP tras denegar GPS y renueva la caché PWA.

- Versión `1.4.1.0`, build `20261126.1`, canal `stable`; API v1 compatible.
- Ejecutar `php spark migrate --all` y configurar los contactos `legal.*`.
- Instalar cron en el hosting: `python3 tools/install-sync-cron.py --php /ruta/php --install`.
- En hPanel, usar la alternativa sin Python de la [guía operativa](../SINCRONIZACION_AUTONOMA.md).
- Preservar `.env`, `vendor/`, base y `writable/`. Sin cambios Composer.
- Android permanece en su repositorio independiente; esta entrega publica el backend web.

Validación local: suite de arquitectura/HTTP/mapas/privacidad, instalación y
ejecución de cron simulado, códigos de salida CLI, PHPStan y lint PHP aprobados.
MariaDB desechable: migraciones, repositorios, paginación, 40 comprobaciones de
reportes, atomicidad de alertas y 27 casos HTTP por cada raíz web, con evidencia de
consentimiento persistida. ZIP de actualización comprobado con scripts y migración.

La instalación y comprobación de cron en el hosting siguen siendo un paso del
despliegue; estas pruebas locales no confirman su activación en producción.
