# SIGRA · versiones 1.0.4 y 1.1.0 · 12 de noviembre de 2026

La versión actual en código es **1.1.0 · API y contratos**, build `20261112.2`.
La **1.0.4 · Filtros y presentación** conserva su entrada propia en el historial.
El contrato de API sigue siendo `v1` y la versión Android sigue siendo `1.0.0`.

## Cambios de 1.0.4

Radio seleccionable desde el inicio, ubicación solicitada al elegir distancia,
consulta por IP con tiempo límite, reintento y soporte sin almacenamiento local.
Traducción ES/EN del historial y canal de versiones, iconos SVG locales y caché
de scripts/estilos actualizada por red.

## Cambios de 1.1.0

Validación de tipos, rangos y parejas de coordenadas en ambas APIs. Se rechazan
JSON malformado (400), datos inválidos (422), contenido no admitido (415) y
tokens opcionales inválidos (401). Las cadenas booleanas se normalizan.
La autenticación, construcción de servicios y consulta de datos quedan dentro
del manejo de errores JSON. Se aplican `no-store` y cabeceras de versión a todas
las respuestas de estos endpoints, incluidos errores. Las claves se comparan
con `hash_equals`; en producción las rutas protegidas rechazan el acceso si no
hay clave configurada. Se conservan rutas y campos de respuestas válidas.

| `python3 tests/ApiHttpTest.py` | 55 comprobaciones aprobadas mediante PHP-CGI: rutas, filtros, autenticación, validación, cabeceras y errores controlados |
| `php tests/ApiResponsesTest.php` | 60 comprobaciones aprobadas de respuestas de controladores con persistencia aislada: filtros enviados al modelo, metadatos, detalle 404, listas vacías, dispositivos y tokens opcionales |
| `node tools/test-map-filters.js` | Regresión de carga inicial, radio, permisos, reintento, almacenamiento bloqueado, limpieza durante espera y tiempo límite por IP aprobada |
| Pruebas existentes de fusión y presencia de métodos API | Aprobadas; las pruebas antiguas de métodos no demuestran respuestas correctas |
| Sintaxis PHP | Sin errores en los archivos PHP modificados |
| `/acerca-de` mediante CGI, ES/EN | Versión 1.1.0, build 20261112.2 y seis entradas de historial traducidas |

Las pruebas CGI usan PHP 8.2.12 de `/opt/lampp/bin/php-cgi`. Las pruebas PHP de
controladores y de fusión se ejecutaron con el PHP 8.5.12 disponible en el entorno.
Los secretos de prueba existen solo en los subprocesos; `.env` no se modifica.
No se crean dispositivos, detecciones ni alertas reales. Los casos de fallo
de MySQL fuerzan una conexión de prueba inaccesible.

## Límites

No se comprobó el servidor Spark del usuario desde el entorno de ejecución.
Las respuestas exitosas con persistencia aislada no validan SQL, transacciones
ni escrituras en MySQL. Queda pendiente comprobar alta/latido/detección/baja con
una base aislada real y un cliente Android, además de FCM y revisión visual web.
Los hallazgos sobre edición/eliminación y CSRF de la revisión del 11 de noviembre
pertenecen a los formularios web y no se resolvieron en estos cambios de API.
