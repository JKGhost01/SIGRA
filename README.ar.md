## نبذة عن المشروع

SIGRA تطبيق PHP مفتوح المصدر يجمع بيانات الزلازل المنشورة من **SGC وUSGS وEMSC وGeoNet وGEOFON/GFZ وINGV** في خريطة قابلة للبحث، مع سجل تاريخي ومرشحات وواجهة JSON API وبلاغات خاصة من المواطنين. يتيح مرشح المسافة البحث عن الأحداث القريبة من موقع محدد.

شبكة مستشعرات الهواتف **تجريبية**. لا يتنبأ SIGRA بالزلازل، ولا يضمن إنذارًا مبكرًا، ولا يحل محل السلطات أو أنظمة الإنذار الرسمية. يُطوّر تطبيق Android بصورة مستقلة في [SIGRA_MOBILE](https://github.com/JKGhost01/SIGRA_MOBILE).

## الوظائف ومصادر البيانات

- خريطة Leaflet وسجل تاريخي وصفحات تفاصيل ومرشحات للمكان والمصدر والمقدار والمسافة.
- SGC لكولومبيا؛ وUSGS وEMSC وGEOFON لتغطية عالمية ضمن حدود كل مصدر.
- GeoNet لنيوزيلندا؛ وINGV لإيطاليا والمناطق المجاورة.
- API للويب وAndroid، وبلاغات خاصة، وتطبيق PWA قابل للتثبيت.
- توحيد البيانات وربط الملاحظات بين المصادر؛ مع الاحتفاظ بالأحداث المخزنة عند تعطل الاتصال بمصدر.

تختلف التغطية وتواتر التحديث بين الفهارس. لا تثبت استجابة HTTP السليمة حداثة البيانات علميًا أو اكتمالها. راجع [المصادر وحدودها](docs/FUENTES_SISMICAS.md).

## التثبيت

المتطلبات: PHP 8.2 أو أحدث مع `curl` و`intl` و`mbstring` و`mysqli`، بالإضافة إلى Composer 2 وMySQL/MariaDB. يوجد CodeIgniter ضمن `system/`، وتُثبّت الاعتماديات وفق `composer.lock`. تتطلب الاختبارات أيضًا Node 22 أو أحدث وPython 3 وPHP-CGI.

</div>

```bash
git clone https://github.com/JKGhost01/SIGRA.git
cd SIGRA
composer install
cp .env.example .env
php tools/setup-local.php
```

<div dir="rtl">

أنشئ قاعدة بيانات فارغة واضبط `database.default.*` و`app.baseURL` في `.env`، ثم نفّذ:

</div>

```bash
php spark migrate --all
php -S 127.0.0.1:8080 -t public
```

<div dir="rtl">

افتح <http://127.0.0.1:8080/index.php/sismos>. يجب أن تكشف التثبيتات الجديدة مجلد `public/` فقط للويب. اتبع [دليل التثبيت الكامل](docs/INSTALLATION.md) لضبط المفاتيح والصلاحيات.

## الإعداد والمزامنة

| الإعداد | الاستخدام |
|---|---|
| `CI_ENVIRONMENT` | `development` محليًا و`production` على الخادم. |
| `app.baseURL` | العنوان العام مع شرطة مائلة في النهاية. |
| `APP_API_TOKEN` | رمز Bearer للمسارات المحمية. |
| `database.default.*` | الاتصال بقاعدة البيانات. |
| `encryption.key` | مفتاح تشفير خاص. |
| `quakes.*` | المصادر والمرشحات والفواصل الزمنية. |
| `sigra.version`, `sigra.build` | قيم اختيارية لتجاوز بيانات الإصدار. |

تطلب الخريطة التحديث تلقائيًا. الفاصل العام الأدنى خمس دقائق، ويستخدم SGC فاصلًا قدره خمس عشرة دقيقة لكل مضيف. تتشارك العمليات الذاكرة المؤقتة والأقفال وفترات الانتظار بعد الأخطاء. استخدام cron اختياري. لبدء مزامنة عادية:

</div>

```bash
php spark sigra:sync
```

<div dir="rtl">

يحترم الأمر الفواصل الزمنية وقد يكتب أحداثًا في قاعدة البيانات. تعرض `/acerca-de#sources-health` الحالة المسجلة؛ ولا يؤدي تحديث هذه اللوحة إلى إرسال طلبات للمصادر. احتفظ بمجلد `writable/cache/providers` أثناء النشر.

## API والخصوصية والتحقق

تستخدم المسارات المحمية `Authorization: Bearer <APP_API_TOKEN>`. راجع عقود [الزلازل](docs/API_SISMOS.md) و[شبكة المواطنين](docs/API_RED.md) و[OpenAPI](docs/api/openapi.yaml). يبقى إصدار العقد `v1`.

مشاركة الموقع اختيارية. عند استخدام تحديد الموقع التقريبي عبر IP كبديل، فإنه يعتمد على `ipapi.co`. لا تنشر الرموز أو بيانات الاعتماد أو البلاغات الخاصة في القضايا العامة.

</div>

```bash
composer test
composer analyse
python3 tools/check-git.py
```

<div dir="rtl">

تتطلب اختبارات MySQL قاعدة اختبار مؤقتة ومحددة صراحةً؛ لا تستخدم قاعدة الإنتاج.

## التحديث والوثائق

يعيد الإصدار 1.3.1.3 توافق HTTP مع SGC. تلقى الاختبار المحلي الفعلي HTTP 200 ووحّد 100 حدث، ثم أكد المستخدم نجاح الإصلاح بعد نشره. لا يضيف هذا التحديث ترحيلات جديدة لقاعدة البيانات. راجع [الملفات المطلوب رفعها وخطوات التراجع](docs/SGC_CONEXION_2026-11-19.md).
